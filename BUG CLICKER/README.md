# SHIKOTO BUG CLICKER PLUGIN
Made by WYKX (@xkwykyx on twitter/x)

## How to use:
1. Install Bug Clicker on https://bugndev.web.app/#clk
2. Execute the file and right click on the default character
3. Click on 'open settings' and go to 'share'
4. Download the '.cvclk' files in this folder
5. Import the files in Bug Clicker
6. You can customize the movements and add features if desired on the application!
